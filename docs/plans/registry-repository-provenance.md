# Add registry repository provenance

Status: implemented and verified; implementation review and draft PR pending. Minimal additive scope.

## Outcome and ownership

Add a registry repository row to normal CLI `pkg info` and MCP `pkg_info`, and an optional JSON `registryRepository: {id,name,url}`. Retain descriptors in existing dependency/vulnerability shared identities. Core service owns GraphQL composition and evidence identity; shared response formatters own CLI/MCP presentation. Backend owns acquisition proof. No backend edits or infrastructure.
